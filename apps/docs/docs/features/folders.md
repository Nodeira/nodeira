# Folders

**Folders** organise notes within a vault. They are optional — notes can exist at the vault root without a folder.

## Operations

| Action   | Description                                                  |
| -------- | ------------------------------------------------------------ |
| Create   | Give it a name inside any vault                              |
| Rename   | Change the folder name at any time                           |
| Set icon | Pick an emoji to display next to the folder name             |
| Delete   | Removes the folder; notes inside are moved to the vault root |

## Icon support

Each folder can display an emoji icon next to its name. Click the folder icon in the sidebar to open the picker and choose an emoji, or clear it to return to the default folder icon.
